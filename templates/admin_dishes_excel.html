📋 操作步骤：
1. 打开学校给的 Excel
2. 找到**一个窗口**的菜单块（例如"粤式风味 · 午餐"）
3. 选中**从"星期一"到"星期日"那 7 列**（含表头也行，会自动跳过）
4. Ctrl + C 复制
5. 粘到下面文本框
6. 选窗口 + 餐次 → 点导入

💡 每个单元格内如果有 、 分隔的多个菜，会自动拆成多道，各带同一个星期。
